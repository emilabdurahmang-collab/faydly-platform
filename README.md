# FAYDLY

Первая публичная демонстрационная версия FAYDLY — платформы взаимных предложений и потребностей.

## Запуск

```bash
npm start
```

Сервер слушает порт `PORT` (по умолчанию 3000). Проверка: `/health`.

**Важно:** это демонстрационный интерфейс без регистрации, сохранения анкет и подключения к Supabase. Не вводите реальные персональные данные.
